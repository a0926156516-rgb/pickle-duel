# 匹克球對決 Pickle Duel

手機瀏覽器就能玩的匹克球對戰遊戲（繁體中文）。單打 1v1、雙打 2v2，線上最多 4 人用 4 位數房號組隊，空位由電腦補上。

- 純靜態網站：`index.html` + `style.css` + `js/core.js`（規則／物理／AI）+ `js/main.js`（畫面、操作、音效、連線），可直接放 GitHub Pages。
- 線上連線沿用《攀岩》peak2d 的 WebSocket 中繼伺服器與協定（`create` / `join` / `msg`，房主權威）：預設 `wss://panjian-peak2d.onrender.com/ws`，可用 `?server=ws://host:port/ws` 改接。`server/relay.js` 是同協定的本機版（從 peak2d `server.js` 取出房間中繼部分），測試或自架用：`cd server && npm i && PORT=10000 npm start`。
- 網址參數：`?room=1234` 帶入房號、`?auto=1` 自動駕駛（展示／測試）、`?fps=1` 顯示 FPS。

## 畫面與角色（v2）
- 直向為主（v3a 起）：手機直拿，球場直放、球網橫跨中間、上下各有廚房區，自己的隊伍永遠在下方（線上每個人都一樣）；移動搖桿在左下、抽球／吊小球／高吊在右下，都在球場下方，不會蓋到球場。球場依 visualViewport 盡量放大（含網址列／App 內建瀏覽器工具列伸縮）。
- 畫面風格（參考使用者提供的直式網球手遊影片，只取鏡頭／氛圍，不使用其品牌）：高位置的近端鏡頭、透視（近寬遠窄）、鏡頭左右平移追球；深色霓虹球場、紫灰斑駁地面與發光紫色紋路、細白線、廚房區淡紫色；黑色球網加粗白邊；遠端看台人影，「匹克球對決 PICKLE DUEL」品牌字放在右上角（v4 起不再放在遠端牆上，避免壓在遠端球員頭上）；黃色發光球與拖尾、落地白色粒子；左上角精簡記分板；白框半透明搖桿與圓形按鈕（抽球有球拍圖示）。
- 裝置橫放時改用橫向版面（左隊 vs 右隊、球網直立），不會擋住遊戲；旋轉、網址列伸縮、任何尺寸變動都會即時重排，畫面迴圈有錯誤保護不會停。
- 角色沿用遊戲模組部門的 peak2d 角色表（`assets/`：阿岩 `male.png`、小攀 `female.png`，72×127 影格，idle／walk）。顏色由 mask 在執行時上色（紅／藍／綠／黃；`tools_build_masks.py` 另把頭盔與鞋子的藍綠色加入換色區，原始角色檔不變），選單可選角色與顏色並即時預覽。揮拍動作是程式合成（手臂＋球拍旋轉、擠壓），未新增美術。
- 顏色分配：玩家保留自己的顏色（撞色時改給空的顏色），電腦補位用剩下的顏色與另一個角色；隊名取隊長顏色（例如「藍隊」）；線上房間的座位預覽、比賽中的顏色與隊名在所有人畫面一致。
- 手機上的球放大 1.5 倍、加深色外框與地面陰影，球場內紋路調淡；遠端球員有最小尺寸。
- 隊伍辨識：腳下光圈與名牌底色＝隊伍顏色（取自該隊第一位）；衣服與球拍＝各自選的角色與顏色（大廳有說明）。
- 提示框（發球提示、兩跳提示）放在對面廚房區；得分／失誤框放在自己這半場不會擋住自己球員的位置；橫向的失誤框在畫面上方。
- 新手提示（簡單／普通）：對方回球時在預測落點畫黃色光圈。

## v14
- 飛撲更常出現：普通／困難電腦偶爾會把球打到對手差一步的斜角（飛撲帶），飛撲帶略為加寬；電腦對電腦約每分鐘 1 次（普通）到 1.2 次（困難），簡單較少；撲救後對手會把高球打向空檔，飛撲方多數仍會輸掉該分。
- 新增「🤸 飛撲練習」（選單殺球練習旁，或 `?demo=dive`）：電腦把球餵到你差一步的地方，面板顯示飛撲次數、救回數與救回率。
- 第一次飛撲時顯示一次性提示「球太遠時會自動飛身撲球！」（存在 localStorage）。
- 「飛撲！」字卡顯示時隱藏該球員名牌，不再重疊。
- 桌機直向（非觸控）比賽時鏡頭底部多留空間，底線飛撲的角色完整可見，鍵盤說明不蓋角色。
- 撲救回球留下淡淡的金色弧線軌跡；該分結束後顯示「救球成功！」／「救球失敗」。

## v13
- 新增「飛身撲球」：球在正常揮拍範圍外、但只差一點（多 0.95 公尺以內、高度 1.3 公尺以下），而且正在離你遠去時，角色會自動飛撲把球救回去。正常範圍內照常揮拍；更遠、太高、或本來就會出界的球不會撲。
- 撲救回球偏弱偏高（約為抽球一半的速度、落在對方中場），對手容易處理；撲完會趴地 0.55 秒，起身期間移動變慢，直到 1.15 秒後才能再擊球，不會太強（電腦對電腦統計：撲救的一方仍輸掉約 65% 的那一球）。
- 電腦也會飛撲：每顆落在飛撲範圍的球依難度有 30%／50%／70% 機率撲（簡單／普通／困難，每球決定一次）。殺球練習不會飛撲，練習計分與數據不變。
- 動畫：身體沿飛撲方向橫躺、地面拖痕與揚塵、「飛撲！」字樣、專屬音效（共用 8 聲道音效池）、輕微震動；直向、強制橫向、橫向都一樣清楚。
- 連線：由房主判定並同步撲球狀態（趴地／起身時間與方向），來賓看到自己的角色撲出去並同樣受起身限制。

- 「現在！」和殺球鍵不再互相矛盾：殺球鍵的「殺球／抽 ▼」和「現在！」用同一個擊球點預測；提示亮起時按鍵一定顯示「殺球」（若原本是「抽 ▼」會立刻改回），測試逐格檢查兩者一致。
- 殺球練習「慢動作」：面板可切換 關／0.5×／0.35×（記住設定；網址 `?slow=0.5` 或 `?slow=0.35`），只在練習中放慢遊戲時間。
- 練習不再連續快速餵球：一球結束後約 3 秒才餵下一球，也可以按任一擊球鍵立刻餵球（提示「按任一擊球鍵就餵球」）。
- 練習「預備」：來球飛來途中（或餵球前）按下殺球，按鍵會保留到擊球那一刻（按鍵上顯示「預備」）；球夠高就殺球，球太低則自動改為一般抽球，不會在廚房區內截擊。對輸入延遲的玩家和初學者都比較容易殺到球。

- 殺球音效每一下都會響：先把殺球聲預先算成音訊緩衝，再用 8 個聲道輪流播放，全部忙碌時中斷最舊的一個。

## v8
- 殺球鍵的「低球」狀態不再閃爍：只在球正朝自己這邊飛來、而且自己來得及合法擊到時才判斷；用預測的擊球點高度（不是球當下的高度）；新狀態要維持 0.35 秒才切換，每一顆來球最多切換一次，兩分之間保持不變。低球時只顯示「抽 ▼」。

- 殺球致勝或逼出失誤時，畫面跳出「SMASH!」字卡（自己隊伍粉紅、對手藍色）。

## v7
- 殺球平衡：主動按「殺球」打 0.9 公尺以上的高球時，會往深處（底線前 0.5–1.8 公尺）、往對手空出來的邊線殺；電腦接殺球時依難度有機會接不到、打掛網／出界或只能擋成又短又高的機會球，越高的擊球點、越遠離對手的落點越難接。實測（腳本玩家整場對電腦、每個難度 20 局）：單打 簡單 約 49%、普通 約 34%、困難 約 26% 的殺球直接得分或逼出失誤（v6 約 29%／21%／15%，且幾乎沒有直接得分）；雙打 46%／35%／24%。

- 失誤訊息標明是誰：「小攀（對手） 失誤・換你方發球」「峻慶（你） 失誤・換對手發球」。
- 遠端名牌不會被記分板擋住；提示框放在自己底線下方，球飛過提示框時提示會變透明；橫向的失誤框放在記分板與右上按鈕之間，不蓋住品牌字與比分；品牌字在所有版面都在右上角；鍵盤說明不再壓到 fps。

## 連線狀況（v4）
- 房主切到背景：房主送出「暫離」，全房間暫停，來賓顯示「等待房主…」；房主回來後 0.9 秒再繼續，時間差有上限，球不會瞬移。房主被系統凍結沒有任何事件時，來賓 1.6 秒沒收到畫面也會顯示等待。單人模式切到背景會自動暫停。
- 自動重新加入：比賽中的來賓重新整理或重開 `?room=` 連結（10 分鐘內）會自動回到原座位，不必再按；自動產生的暱稱存在本機，重新加入後不變。回到比賽的提示以自己隊伍在前（和記分板一致）。

## 規則
低手對角發球、發球不可落廚房區（含線）、兩跳規則、廚房區（非截擊區）截擊犯規與截擊後衝入廚房、出界、掛網、兩次落地；只有發球方得分，11 分領先 2 分（可選 7／15 分）；雙打報分「發球方-接發球方-發球員號碼」，開局 0-0-2，得分時發球員與隊友換邊。

## 操作
- 手機：左下搖桿移動（直向）／左側搖桿（橫向）；右下 抽球／吊小球／高吊／殺球。球進入範圍自動揮拍，移動方向控制左右落點；違規的截擊不自動揮拍，但主動按鍵就會照打（並判犯規）。
- 電腦：WASD／方向鍵移動，J／空白 抽球、K 吊小球、L 高吊、I 殺球，Esc 選單。
